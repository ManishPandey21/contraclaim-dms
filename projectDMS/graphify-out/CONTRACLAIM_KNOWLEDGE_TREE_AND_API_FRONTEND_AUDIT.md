## Executive Summary

- FastAPI route inventory: 363 route decorators across 41 router modules. Static frontend reference check found 286 obvious frontend-linked routes and 77 routes without an obvious non-test frontend reference.
- Architecture is feature-rich: FastAPI/Motor/MongoDB, Vite React, HttpOnly cookie JWT + CSRF, central policy/RBAC, document file-object/version storage, contract ingestion, Qdrant/FalkorDB/Graphiti, LangGraph/Pydantic AI, and Razorpay gateway abstractions.

- Razorpay is partially implemented for subscriptions and webhooks, but checkout/order/payment verification/receipt/failure-retry UX is not production complete.

## Backend Modules

- `main.py` registers API routers, request context logging, CORS, CSRF middleware, startup/shutdown, scheduler and background hooks.
- `core/config.py`, `database.py`, `security.py`, `csrf.py`, `permissions.py` own runtime settings, Mongo indexes, JWT/cookie auth, CSRF, and canonical permissions.
- `routers/*` contains the API layer; the largest surfaces are `rbac_monetization.py`, `documents.py`, `letter_drafting.py`, `contract_appraisal.py`, `letters.py`, `ai_assistant.py`, `claims.py`, and `permissions.py`.
- `services/*` contains business logic: document/file storage, contract ingestion/search, policy/entitlements, letter drafting, billing/payment gateway, webhook processing, storage sync, notification/email, observability.
- `ingestion`, `retrieval`, `agents`, `graph`, and `ai_workflows` are first-class AI/RAG subsystems.

## Frontend Modules

- `config/api.ts` resolves API base from `VITE_API_BASE_URL`, `window.__API_BASE_URL__`, host-derived `https://api.contraclaim.com/api`, or `/api`.
- `services/http.ts` sends credentials, injects CSRF, and wraps authenticated fetch/Axios.
- `services/*` wraps documents, contracts, claims, billing, storage, SMTP, letters, search, tasks, tags, auth, session, dashboard.
- `components/auth/*`, `hooks/useRBAC.ts`, and `config/rolePermissions.ts` provide frontend permission UX.
- Major pages exist for documents, contracts, letter drafting, claims, SLA, reports, settings, plan settings, subscription management, users/permissions/orgs/projects.
- `client/src/pages/bulk-upload-service-fixed.py` is a backend-style artifact inside frontend source and should be relocated or removed.

## Authentication and RBAC

- Auth flow: `LoginPage.tsx` -> `services/auth.ts` -> `POST /api/login` -> `routers/auth.py` -> JWT in HttpOnly `cc_access_token`; CSRF via `cc_csrf_token` and `X-CSRF-Token`.
- Current user: `GET /api/me` and `core/security.py:get_current_user` load role/org/project scope.
- Sensitive billing/admin actions use `POST /api/step-up` and frontend `useStepUp.tsx`.
- Backend authority is `PolicyService`, `AuthorizationService`, `PermissionService`, `EntitlementService`, and `ScopeService`; frontend guards are UX only.
- Gap: frontend route permission map is smaller than backend route surface; add generated permission parity checks.

## Document Upload and Processing

- Single upload path: `UploadPage.tsx`/`DocumentsPage.tsx` -> `POST /api/documents` -> stream temp file, MIME sniff, SHA-256, size limit, optional ClamAV -> local/S3 storage -> file object dedupe -> `documents` + `document_versions`.
- Processing path: `POST /api/documents/{id}/process` -> `DocumentProcessor` OCR/text/metadata/vector persistence.
- Bulk path: `POST /api/documents/bulk-upload`, status endpoint, template endpoint, `bulk_upload_jobs`.
- Download path: local allow-list or S3 presigned fallback plus audit event.
- Gaps: expose retry/failure states for ClamAV, OCR, S3, vector indexing, and worker delays.

## AI/RAG Flow

- Ingestion: `/api/v1/ingestion/jobs` -> chunking -> embeddings -> Qdrant -> Mongo chunks/jobs/vector sync -> observability.
- Retrieval: `/api/v1/retrieval/search` and `/rag` -> Qdrant or Mongo fallback -> citations -> LLM generation.
- Contract QA: `/api/v1/retrieval/contract-qa` -> iterative clause retrieval, critique/refinement, citation enforcement.
- Contract upload/search: `/api/contracts/*` -> `ContractService` and `contracts_ingest.py` -> clause chunks, `document_vectors`, graph/vector indexing.
- Letter AI/LangGraph: `/api/ai-assistant/*` and `/api/letters/{id}/drafting/*` feed hooks/components for drafting and planning.
- Gaps: missing/partial admin UX for ingestion jobs, vector reconciliation, graph health, RAG run logs, prompt versions, model config, failed AI jobs.

## Findings, Risks, and Gaps

1. Critical: Razorpay checkout is not fully wired to a user-facing page; `billing-api.ts` appears unused outside itself.
2. Critical: No dedicated Razorpay order creation or payment verification endpoint was found.
3. High: Many backend APIs are unlinked from frontend workflows; expected for webhooks/ops, risky for billing/admin/storage/AI surfaces.
4. High: Duplicate/legacy surfaces exist: `roles.py` plus role endpoints in `permissions.py`, legacy `/api/token` and `/api/logout`, email legacy/new split.
5. High: Frontend permission names rely on aliases and manual route map; add generated backend/frontend permission parity.
6. Medium: `.env.example` has `CLAMAV_FAIL_OPEN=true`; production antivirus should fail closed.
7. Medium: Operational views for queues, ingestion, vector sync, graph, webhook events, external service health are behind backend capability.
8. Medium: Misplaced frontend Python file indicates cleanup needed.
