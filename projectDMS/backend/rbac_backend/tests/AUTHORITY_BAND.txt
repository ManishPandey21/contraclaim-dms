# AUTHORITY BAND — permanent document/graph publication-authority regressions.
#
# (Formerly called the "G31 Band". Renamed because G29/G30/G31/G32 are graph
# CERTIFICATION GATES; this file is a pytest regression suite and is not one of
# them. A green Authority Band is not a certified gate.)
#
# These are the accepted regressions that pin who may write derived graph and
# evidence material, and whose final state may influence a consumer. They are
# load-bearing: any ticket that touches a production seam intersecting graph or
# Document publication authority runs this band BEFORE and AFTER its change,
# and the two runs must be comparable.
#
# Run it:
#
#   backend/.venv/Scripts/python.exe -m pytest \
#       $(grep -v '^#' backend/rbac_backend/tests/AUTHORITY_BAND.txt) -q
#
# Only `backend/.venv` has the full dependency set; other interpreters produce
# phantom collection errors.
#
# Rules:
#   - never delete a line from this file;
#   - never weaken an assertion in a listed file to make new code pass;
#   - a new authority regression must be ADDED here (test_authority_band_manifest.py
#     fails if a discovered one is missing);
#   - the ENTRIES are the contract. Any count is observational only, and the
#     guard deliberately permits the band to GROW.
#
# What the guard pins, and what it does not:
#
#   - REQUIRED_SLICE_FILES     - the thirteen accepted vertical slices;
#   - REQUIRED_GRAPH_GATE_FILES - the graph certification-gate regressions
#     (the five Falkor suites plus the four reader/consumer files below);
#   - anything else here is a legitimate member whose deletion the discovery
#     rule is expected to catch. Adding a member needs no guard edit unless it
#     is outside both discovery patterns, in which case pin it by name.
#
# Being pinned means the regression may not disappear. It does NOT mean the
# gate it belongs to is closed: G29/G30/G31/G32 are all OPEN. See
# .claude/context/contract-master/GRAPH-GATES.md.
#
# If a Contract Master change conflicts with an accepted invariant in this band,
# STOP. Do not adjust the regression to fit the implementation.

# --- G-A20 containment: G32-STATE legacy graph migration and its validator.
# G32-CODE stopped the writer contaminating the shared (:Letter) node and stopped
# every reader reading one. Neither touches state that already exists: 215 nodes
# still carry document/tenant-owned properties and 307 of 310 CITES edges have no
# owner_document_id, so they can never be retracted by any cleanup path. These two
# suites pin the rules the migration over that state obeys, under the accepted R11
# amendment (GRAPH-GATES.md, "R11 / U3 - owner amendment"): ownership comes only
# from canonical Mongo evidence; an ambiguous owner is never guessed; NULL is a
# valid terminal state; owner_document_id='' is never an outcome and a pre-existing
# one is repaired; a non-NULL owner naming no canonical document is INVALID, not
# valid; a dry run writes nothing; and the production graphs are structurally
# unreachable without a recorded authorization.
# Evidence toward G32-STATE. The gate is NOT certified by it, and a green run
# against a disposable graph proves nothing about deployed state.
