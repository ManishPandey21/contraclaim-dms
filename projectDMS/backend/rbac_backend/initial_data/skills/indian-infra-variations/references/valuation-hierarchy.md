# Variation Valuation Hierarchy

Apply in strict order:

1. **Contract rates** – work of similar character executed under similar conditions.
2. **Derived rates** – similar character but dissimilar conditions; adjust the Contract rate for the difference.
3. **Cost plus reasonable profit** – no applicable or reasonably derivable rate exists.
4. **Daywork** – only when specifically instructed and daily records are kept.

For omissions: value at the rates that would have applied had the work been executed, then deduct.

Always record which limb is used and the justification.
