# Recommended Hearing Structure (Indian Construction Arbitration)

Typical sequence:
1. Opening statements (Claimant then Respondent)
2. Claimant’s evidence (witness statements + oral examination / cross)
3. Respondent’s evidence
4. Concurrent expert evidence / hot-tubbing (if directed)
5. Closing oral submissions
6. Post-hearing written briefs (if ordered)

Materials should be prepared so that counsel can move flexibly if the tribunal changes the order or time allocations.
