# Letter Analysis Checklist

Quick verification points:

1. Is it a formal notice under the Contract (FIDIC 1.3 / equivalent)?
2. Was it served within the contractual time limit?
3. Does it contain the minimum required particulars?
4. Are the cited clauses correct and complete?
5. Does it create any admission or waiver risk?
6. What happens if no reply is sent?
7. Is a protective counter-notice required?
8. Does it trigger any determination timeline (e.g. FIDIC 3.7)?
9. Link to any existing claim, variation or EOT register entry.
10. Recommended specialist skill for deeper analysis.
